# AI Basket Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A private Telegram bot that saves every AI resource mentioned in a YouTube Short, link or typed text to a Google Sheet with a real link and a short description, and finds them again with `/find`.

**Architecture:** Three n8n workflows (Bot, Process, Retry) on Deshik's self-hosted n8n. All decision logic lives in small pure JavaScript files in `src/lib/`, unit-tested with `node --test`, and inlined into n8n Code nodes by a build script. Workflows are written as n8n Workflow SDK source in the repo and pushed to n8n through the n8n MCP tools.

**Tech Stack:** n8n (Workflow SDK, Telegram Trigger 1.5, Telegram 1.2, Google Sheets 4.7, Google Gemini 1.2, HTTP Request, Code 2), Node.js 22 built-in test runner, Gemini API free tier, NVIDIA NIM free API, skills.sh, Tavily free plan.

**Spec:** `docs/superpowers/specs/2026-10-06-ai-basket-design.md`

## Global Constraints

- Running cost ₹0. Gemini key's Google project has **no billing account**. Tavily free plan. NIM free endpoint. No paid node or service anywhere.
- An AI never writes a URL. Links come only from: the shared message, a link the AI reports as shown/said in the video, a skills.sh result, or a Tavily result chosen **by index**.
- Secrets live only in n8n credentials. Never in the repo, fixtures, chat or logs. Scrub keys from any captured response.
- Credential names: `AI Basket Telegram` (new), `NVIDIA NIM` (new, Header Auth `Authorization: Bearer …`), `Tavily` (new), `Google Sheets account` (existing, id `w6TcJFWBRSpoifCL`), `Google Gemini(PaLM) Api account` (existing, id `GzWPqEIKL3sEzEJR`).
- Workflow names: `AI Basket – Bot`, `AI Basket – Process`, `AI Basket – Retry`.
- Sheet `AI Basket`, tab `resources`, columns in this order: `saved_at, name, category, description, link, link_from, prompt_text, source_url, note, status, attempts`.
- Categories exactly `Skill | Tool | Prompt | Website`. Icons `🧩 🔧 💬 🌐`. `link_from` exactly `source | shared | skills.sh | search | not found`, or blank for a Prompt with no link (spec: "normal, not not found"). `status` exactly `ok | pending | check`.
- Limits: max 5 URLs per message · page text 8,000 chars · Tavily top 5 · description ≤ 200 chars · prompt preview 100 chars · Telegram message ≤ 4,096 chars · `/find` top 10 · retry every 6 h · max 3 attempts · link check timeout 10 s, status ≥ 400 = not found.
- `saved_at` in Asia/Kolkata, format `YYYY-MM-DD HH:mm`.
- Reply copy exactly as in spec §3 and §6 (`⏳ Working on it…`, `Already saved on <date>`, `Already queued, will retry`, `⏸ Saved for later, will retry`, `⚠️ Couldn't watch this, saved to check manually`, `❌ Not saved, send again`, `Nothing found in this one`, `Nothing for "<query>".`, `…and N more. Add a word or open the Sheet.`).
- Code nodes have no network access. Every HTTP call is an HTTP Request node (or the Gemini node).
- Gemini video node: `maxOutputTokens` 2048 (node default 300 truncates the JSON).
- Every node that calls an outside service uses `onError: 'continueErrorOutput'` and its error output is wired to a handler. No silent failure. Exception: Telegram send nodes (nowhere to report; the n8n execution log shows it).

## Review Focus

1. **Truncated or invalid AI JSON** (model cut off, prose around JSON) → input saved as `status = check` with ⚠️ reply, never a crash. Pinned in Task 4 (`parseResources` truncated case) and Task 7 (fixture `yt-truncated`).
2. **Message with no text** (photo, voice note, sticker) or **URL hidden behind a hyperlink / in a caption** → no text: reply `Send a link or some text.`; hidden URLs and captions are read. Pinned in Task 3 (`messageText`) and Task 9 (`route` unsupported case).
3. **A Short with many resources** (e.g. "30 AI tools") → every row saved, reply cut to fit 4,096 chars with `…and N more in the Sheet.` Pinned in Task 6.
4. **Very long typed prompt** (6,000+ chars) → full text in `prompt_text`, 100-char preview in reply. Pinned in Task 6 and Task 7 (fixture `text-long-prompt`).
5. **Non-English Short** (Telugu/Hindi speech) → name and description still in English. Pinned in the YouTube prompt (Task 7) and live case L13 (Task 11).
